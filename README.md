# EMS-Website
Employee Management System

Project Description

Employee Management System is a Java-based application developed to manage employee information efficiently.

The system allows users to perform basic CRUD operations such as adding, viewing, searching, updating, and deleting employee records.

EMS Website

A separate frontend website for the Employee Management System was created using HTML, CSS, and Bootstrap in VS Code.

🌐 Live Website:
https://gayathrimurugan20061-del.github.io/EMS-Website/

Features

Java Application

- Add Employee
- View Employees
- Search Employee
- Update Employee
- Delete Employee
- Employee ID validation
- MySQL database connectivity

EMS Website

- Dashboard
- Employee Directory
- Add Employee
- Employee Search
- Attendance
- Payroll
- Reports
- Settings

Technologies Used

Java Application

- Java
- JDBC
- MySQL
- Eclipse IDE

Website

- HTML
- CSS
- Bootstrap

Architecture

The Java application follows a Layered Architecture:

- Model
- Repository
- Service
- Controller

Database

MySQL is used to store employee information.

Employee Table

Field| Description
id| Employee ID
name| Employee Name
email| Employee Email
department| Employee Department
salary| Employee Salary

How to Run

1. Install Java JDK 17.
2. Install MySQL.
3. Create the required database and employee table.
4. Configure the database username and password.
5. Open the project in Eclipse.
6. Add MySQL Connector/J.
7. Run "EMSApp.java".

Project Outcome

The project demonstrates employee management using Java, JDBC, MySQL, along with a separate responsive EMS website developed using HTML, CSS, and Bootstrap.
